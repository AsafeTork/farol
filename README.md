# Farol — assistente de navegação digital

Farol guia idosos, PcD e neurodivergentes pelos fluxos essenciais do gov.br, campo por campo — a internet explicada passo a passo com voz, destaque e paciência.

O assistente lê em voz alta, destaca o campo ativo da tela e explica, em linguagem simples, o que preencher e por quê. Nada é feito no lugar da pessoa: cada passo acontece no ritmo de quem navega.

Projeto de conclusão do IAssistente Intergeracional (IFPA Bragança · SBGAMES 2026).
